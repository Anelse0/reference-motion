# Project-specific design decisions

Start with what the audience should understand and the evidence for that content. Choose a mechanism that makes that relationship visible: organization, comparison, change, causality, or another appropriate idea. Write why it serves this brief. No mechanism here is a required scene or a reusable finished sequence.

For the decisions that matter in this project, record the goal, implementation, units/source, scope, and intended check. Distinguish `user`, `measured`, `designed`, and `inferred` facts. A plausible explanation of a reference is not a measurement.

Consider only relevant questions:

| Area | Decision and evidence |
| --- | --- |
| Content and attention | What changes the audience's understanding? What must be read first? Does decoration hide the main fact? |
| Visual continuity | Which objects persist? Which relationships carry attention between states? Are discontinuities intentional? |
| Timing and movement | Where do density, speed, pauses, overlap and silence help? Do essential words remain readable? |
| Typography and layout | Which loaded font and weight actually render? What are the measured bounds, baseline, wrapping and intentional crop? |
| Effects and material | What does a mask, blur, deformation, light or depth effect communicate? What must remain recognizable? |
| Color | Which role does each color play in this film? Are supplied logos and state colors respected? |
| Sound | What changes density, texture or emphasis? Which events merit sound, and which benefit from silence? |
| Adaptation | On a new aspect ratio, which relationships must be preserved and remeasured? |

The case-study choices—upward motion, one pause, 124 BPM, ten slots, a particular font, blue/mint colors, or no crossfade—are not defaults or learned preferences. Use any of them only when the current task independently selects or requires it.

Storyboard the actual information progression. Each shot or continuous section should name its purpose, frame interval, state changes, handoff and relevant sound anchors. This is an authored result, not a form with a fixed number of rows. Centralize shared event times in the timeline rather than duplicating them in audio, drawings and prose.

Before extending a representative section, distinguish a weak idea from a flawed implementation. Change the content mechanism when the idea fails; repair local geometry or timing when the implementation fails. Inspect real layout and continuous output instead of treating adjectives such as “premium” or “smooth” as evidence.

For match, preference does not authorize changing a locked direction, palette or rhythm. If a requested improvement conflicts with the lock, explain the concrete conflict and obtain the needed scope decision before applying it. A new authorized creative interpretation can become create in a new revision, with the former reconstruction claim retired.
